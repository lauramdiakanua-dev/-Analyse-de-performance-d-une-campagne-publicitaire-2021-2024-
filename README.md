📊 Analyse de performance d’une campagne publicitaire (2021–2024)
🎯 Objectif du projet

Ce projet consiste en l’analyse de la performance d’une campagne publicitaire multi-canaux sur la période 2021–2024.

L’objectif était de :

Mesurer la rentabilité des investissements marketing

Identifier les segments les plus performants

Analyser les performances par réseau social

Optimiser le ciblage en fonction de l’âge et du sexe

🛠 Outils utilisés

Microsoft Excel

Tableaux croisés dynamiques

Segmentation (slicers)

Formules avancées (calcul ROI, taux de conversion, indicateurs synthétiques)

Conception d’un dashboard interactif

📈 KPI analysés

Chiffre d’Affaires généré

Nombre d’impressions

Leads générés

ROI moyen

Taux de conversion

📊 Analyses réalisées

Performance par réseau social (Facebook, Instagram, Twitter)

Rentabilité par centre d’intérêt

Analyse des ventes par tranche d’âge et sexe

Comparaison ROI / Volume de ventes

Le dashboard permet une exploration dynamique via des filtres interactifs (âge, sexe, centre d’intérêt, réseau social).

🔎 Principaux enseignements

Certains réseaux génèrent un volume important mais un ROI plus faible.

Le segment 25–34 ans constitue un levier majeur de performance.

Certains centres d’intérêt présentent une rentabilité supérieure.

Le taux de conversion varie significativement selon le ciblage démographique.
